# AutoSeg: Auto-Vocabulary Semantic Segmentation

Webpage for the paper [Auto-Vocabulary Semantic Segmentation](https://arxiv.org/abs/2312.04539) by Osman Ülger*, Maksymilian Kulicki*, Yuki Asanos and Martin R. Oswald.

This is the repository that contains source code for the [AutoSeg website](https://ozzyou.github.io/autoseg.github.io/).
